# mingo booth

A browser photo booth for the Afrobeats, Amapiano & Afrohouse party at I-House Berkeley, made by mingo.

Open `index.html` in Chrome on a laptop, allow the camera, and press Space.

## What it does

- 4-shot sessions with a countdown, flash and shutter sound
- Two layouts: a 2x6 strip and a 4x6 grid
- Four frames: mingo night, mingo dusk, Yebo, Red room
- Retouch on/off (skin smoothing, brighter faces)
- Filter on/off with five looks: Flash film, Club red, Riso pop, Dusk, Chrome
- Finished photos save to Downloads automatically, and you can switch the frame after shooting

## Keys

| Key | Action |
| --- | --- |
| Space | Start a session |
| 1 to 4 | Pick a frame |
| R | Retouch on/off |
| F | Filter on/off |
| M | Mirror on/off |
| Esc | Stop the countdown |

## Booth settings

Party name, venue, date line and tagline on the frames, camera choice, countdown length, mirror, sound and auto save all live under Booth settings in the side panel. Settings are remembered in the browser.

## Notes

- The camera needs https or a local file. GitHub Pages works.
- Everything runs in the browser. No photos leave the laptop.
